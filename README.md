# 🖼️ **VanshStega - Image Steganography API**

**Spring Boot backend implementing LSB (Least Significant Bit) steganography for secure image data hiding** [file:11]

Hide sensitive data inside images using battle-tested LSB algorithm. REST API with file upload/download endpoints.

---

## 🎯 **What is VanshStega?**

**Industrial-grade steganography service** built with Spring Boot to embed/extract secret messages in image Least Significant Bits (LSB). Perfect for secure data transmission and cybersecurity research.

| Component  | Technology             |
| ---------- | ---------------------- |
| Framework  | Spring Boot 3.x        |
| Language   | Java 17+               |
| Algorithm  | LSB Steganography      |
| Image      | Java AWT BufferedImage |
| Validation | Spring @Valid          |
| API        | Spring REST            |
